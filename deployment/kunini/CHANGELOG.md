# Журнал изменений Kunini deployment

## 2026-11-01

- Добавлен pinned Docker deployment Kavita с loopback-only портом и read-only библиотекой.
- Веб-интерфейс закрыт через Kunini Auth, а штатный API оставлен доступным для персональных API-ключей.
- Добавлены выпуск и обновление TLS-сертификата, production-проверка и инструкция по эксплуатации.
- Контейнер запускается без root от UID/GID владельца production-каталога.
- Созданы администратор `dkunin`, отдельный ключ Kover и библиотека `Books` на `/books`; секреты хранятся на сервере с режимом `0600`.
- Production-проверка теперь подтверждает авторизованный API и штатный вход Kover; логирование URL аутентификации Kover отключено для защиты API-ключа.
