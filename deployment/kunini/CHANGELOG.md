# Журнал изменений Kunini deployment

## 2026-11-02

- Исправлены блокирующие ошибки ESLint; обновлены Angular и транзитивные зависимости, а `npm audit` очищен от известных уязвимостей в development- и pinned production-сборках.
- Домашняя страница получила акцентный блок продолжения чтения, явный прогресс и более спокойную иерархию книжных лент.
- Карточки, навигация и карусели получили улучшенные состояния наведения, фокуса, перенос заголовков и увеличенные области нажатия.
- Добавлена воспроизводимая сборка кастомного UI поверх pinned runtime-образа с проверкой точного Git SHA и документированным откатом.
- UI-патч теперь накладывается на совместимый тег `v0.9.1.4`, чтобы frontend и backend сохраняли один API-контракт.

## 2026-11-01

- Добавлен pinned Docker deployment Kavita с loopback-only портом и read-only библиотекой.
- Веб-интерфейс закрыт через Kunini Auth, а штатный API оставлен доступным для персональных API-ключей.
- Добавлены выпуск и обновление TLS-сертификата, production-проверка и инструкция по эксплуатации.
- Контейнер запускается без root от UID/GID владельца production-каталога.
- Созданы администратор `dkunin`, отдельный ключ Kover и библиотека `Books` на `/books`; секреты хранятся на сервере с режимом `0600`.
- Production-проверка теперь подтверждает авторизованный API и штатный вход Kover; логирование URL аутентификации Kover отключено для защиты API-ключа.
- Браузерный вход переведён с одного только proxy gate на Kunini OIDC с автоматическим входом, стабильной привязкой пользователей и автопровижинингом доступа к `Books`.
- Native password authentication отключена; production-проверка валидирует OIDC discovery/PKCE и отказ парольного входа, не затрагивая персональные API-ключи.
