# Интерфейс Kavita Ink

Ink — изолированная frontend-кастомизация Kavita. Она сохраняет штатные API,
маршруты, права, прогресс чтения, коллекции, списки, OPDS и EPUB/PDF/comic
читатели. Новых backend-зависимостей и таблиц нет.

## Устройство

- `ui-v0.9.1.4.patch`, затем `ui-ink-v0.9.1.4.patch` накладываются на
  совместимый upstream-тег перед сборкой.
- `dark.scss` содержит общие `--ink-*` токены цвета, радиуса и анимации.
- `library-detail` добавляет адаптивные grid/list режимы и фильтры фактического
  прогресса `ReadProgress`.
- `series-preview-drawer` использует реальные Series и SeriesMetadata, вызывает
  штатный `ReaderService` и на мобильном занимает весь экран.
- `entity-card`, dashboard и side navigation только меняют представление;
  контекстные действия и проверки прав остаются Kavita.

Референсы: [desktop](ink-desktop.png) и [mobile](ink-mobile.png).

## Проверка обновления

1. Изменить `ui_source_ref` в `build-ui-image.sh` только после проверки
   совместимости frontend/backend.
2. Пересобрать патч относительно нового тега и выполнить `git apply --check`.
3. Выполнить `npm ci --legacy-peer-deps`, `npm run lint` и `npm run prod`.
4. Собрать образ, проверить desktop/tablet/mobile, grid/list, фильтры, панель
   деталей, поиск, коллекции и каждый тип читателя.
5. Перед production сохранить архив `deployment/kunini/config` и записать
   текущий image/revision label.

## Откат

Быстрый откат не меняет конфигурацию или книги:

```bash
KAVITA_IMAGE='jvmilazz0/kavita:0.9.1@sha256:31181a32f0dda73cae68721867028a7253d57881b58bea5754cd9e578e75421a' \
  ./deployment/kunini/deploy.sh
```

Для точного отката Ink можно также загрузить предыдущий `kavita-kunini:<sha>`
и передать его через `KAVITA_IMAGE`.

## Известные ограничения

- Панель работает на уровне Series — так устроена сетка Kavita; главы и тома
  сохраняют собственные штатные detail-маршруты.
- В компактном list-режиме показываются только поля уже загруженной Series.
  Автор появляется в панели деталей, чтобы не создавать N+1 API-запросы.
- Типовые вкладки библиотек выводятся только для реально доступных пользователю
  библиотек; отсутствующие Comic/Manga разделы не имитируются.
- На телефоне используется штатная off-canvas навигация Kavita, а не нижняя
  панель: так сохраняются поиск, роли, расширения и существующие маршруты без
  отдельной мобильной навигационной системы.
